# Campaigns

Supplied square campaign pieces, 1000 × 1000. They are composition references for photography, code, price and callout placement.

- `campaign-umbrella.jpg`: everyday-use photography with color options and a price.
- `campaign-organisers.jpg`: a white information card (code, materials, sizes, price “cada uno”) beside the product in use.
- `campaign-kitchen.jpg`: a small kitchen solution in context with code and price.

Their embedded prices and promotions are historical, not live offers. When designing new pieces, set code, name and price as live text over new photography (see `PhotoPanel` and `Callout`).
