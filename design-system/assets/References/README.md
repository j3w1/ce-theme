# References

Owner-supplied reference material. These files document approved directions and historical pieces; they are not production assets and their embedded prices and offers are not current. Provenance is in `public/references/manifest.json` in the repository.

- `product-card-wilul.png`: the approved product-card direction — NAME, Description, specifications, previous price and a yellow promotional price.
- `price-label-yellow-historical.png`, `price-label-white-historical.png`: historical 80 × 40 mm gondola labels. Evidence for the `Label` recipe; their headings and layout are not mandatory.
- `campaign-umbrella.jpg`, `campaign-organisers.jpg`, `campaign-kitchen.jpg`: historical square campaign compositions with baked-in text.
- `brand-tote-bag.png`: a brand tote-bag mock-up.

Never copy their baked-in text or prices into new designs. Set NAME, Description, code and price as live text over new photography (`PhotoPanel`, `Callout`, `TaggedMedia`).
