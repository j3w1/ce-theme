# Hosting

The documentation site (`site/`) is published at **https://j3w1.github.io/ce-theme/**.

- **Target.** GitHub Pages for this public repository, at the provider's HTTPS address, with no custom domain, paid service or backend. Astro builds it under the base `/ce-theme/`; hand-written internal URLs go through `url()` in `site/url.mjs`.
- **Release process.** Every push to `main` whose CI run (`.github/workflows/check.yml`) passes deploys, in that same run. `validate` builds the site, runs the output tests in `tests/dist/` and uploads that exact `dist/` as the Pages artifact. B1-release's `publish` and `prove` jobs publish the `@casaelida/vue` version, or verify that the published one has this commit's package contents, and install it from its public URL. Only when all three succeed does `deploy` publish the artifact `validate` uploaded, so the site always documents a version that is public and installable. `deploy` runs one at a time without cancelling a pending deploy (concurrency group `pages`, `queue: max`), and `pages-gate` skips it when its commit is no longer the tip of `main`, so an older build never replaces a newer one. If any job fails, nothing deploys and the previous site stays live.
- **Rollback.** Run the same CI workflow by hand with the input `rollback_commit` (`gh workflow run check.yml --ref main -f rollback_commit=<full sha>`): a commit with an earlier successful `github-pages` deployment, read from the Deployments API, whose package version is already published. The run checks out that commit exactly and runs the same jobs. Its release jobs only verify the version that is already published, and its `deploy` job is the one run exempt from the tip check. Afterwards, the normal correction is a reviewed revert pull request through the ordinary path.
- **Accidental disclosure.** GitHub's native **Unpublish site** (repository Settings → Pages) takes the site down at once and keeps the Pages setup. It is a step for j3w1 or the repository lead, who records it. The next deploy publishes the site again, so the correction merges first.
- **Live check.** After a deploy, the live smoke runs against the published site: `CE_SITE_URL=https://j3w1.github.io/ce-theme/ CE_EXPECT_COMMIT=<deployed sha> CE_EXPECT_VERSION=<X.Y.Z> pnpm exec playwright test -c playwright.live.config.mjs`. A failure is fixed through a reviewed pull request or rolled back.
- **Not a preview.** This is the public documentation of released versions. It is not a development preview, uses none of the development-host preview tooling and does not expire.
