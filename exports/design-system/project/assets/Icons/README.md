# Icons

Original outlined icons for Casa Elida: 24 × 24 grid, 1.7px stroke, round caps and joins, no fill. The SVG files are drawn in ink `#111111`; inline them with `stroke="currentColor"` to take the text color.

`arrow`, `search`, `menu`, `bag`, `heart`, `download`, `copy`, `check`, `sun`, `grid`, `plus`, `close`, `ruler`.

Pair an icon with a word or give its button an `aria-label`. Hide decorative icons with `aria-hidden="true"`.
