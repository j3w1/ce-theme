# Link

Underlined inline text link in ink that turns action red on hover.

## Classes

- `ce-link`: `ce-color-text-primary` with an underline offset of 0.2em; hover uses `ce-color-action-primary-hover`.

## The consumer supplies

A native `<a href>` whose text names the destination (“Explorar el catálogo”), never “clic aquí”.

## Do and don't

- Do keep the underline; color alone does not mark a link.
- Don't use a link for an action that changes data; use `Button`.
