# StandardNamesOutputs

Standard names for print and sharing: **GondolaLabel** (Etiqueta de góndola), **ShareCard** (Tarjeta para compartir).

## Classes

- **GondolaLabel** · Etiqueta de góndola: `ce-label`. 80 × 40 mm: NAME, Description, specs, price (the largest).
- **ShareCard** · Tarjeta para compartir: `ce-share-card`. 1200 × 630 price-free link preview.

## The consumer supplies

Real products, each with a NAME; supplied prices, discount labels and bases. Nothing in a sample is a live offer.

## Do and don't

- Do say the name, not the look: “Precio Promo”, not “the yellow price”.
- Don't rename a pattern or reuse a name for another one; add a new entry to `recipes/names.mjs` in the same change as its recipe.
