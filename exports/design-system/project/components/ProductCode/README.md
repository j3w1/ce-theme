# ProductCode

White-on-black rectangular label that shows a product identifier exactly as supplied.

## Classes

- `ce-code`: `ce-color-code-text` on `ce-color-code-bg`, 14px regular, tabular figures, square corners. Long codes wrap; a click selects the whole code.

## The consumer supplies

The code as a text string: `CE26061509`, `7730744292227`, `CE26031111R/12R`. Render it as text, never as a number or HTML.

## Do and don't

- Do place the code above the product name, in the same position on every piece.
- Don't truncate, reformat, strip leading zeros or swap a code for a model name such as MENE.
